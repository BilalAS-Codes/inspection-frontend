# inspection-frontend

Industrial Inspection & Certification Management Platform — Frontend Application.

Built with Next.js 14, React, Tailwind CSS, Framer Motion, and Lucide Icons.

## Features
- **Corporate Clients & Field Engineers 360° Management**
- **Dynamic Proposals & Public E-Signature Acceptance Flow**
- **ZATCA-Compliant Tax Invoices & Mock HyperPay Gateway**
- **Field Work Orders & Gate-Pass Validated Engineer Dispatch**
- **Equipment Inspection Execution & Tamper-Evident QR Certificates**
- **Gate Pass Vault for Statutory Credentials**

## Getting Started
```bash
npm install
npm run dev
```
Runs at `http://localhost:3000`.
